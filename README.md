## Installation

1. Starta laragon
2. Öppna HeidiSQL och skapa ny databas 'bankproject'
3. Kör Schema.sql via HeidiSQL
4. Kör i terminalen - C:\laragon\bin\php\php-8.3.30-Win32-vs16-x64\php.exe Seed.php
5. öppna - http://localhost/BankProject/public
